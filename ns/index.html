Mindstr vocabulary

https://mindstr.org/ns#: the terms of the mindstr mind map format, used as @vocab in map documents (SPEC.md) and in Nostr kind 30627 events.

The map

version
Format version of the document, e.g. "0.2". A missing version means "0.1".
nodes
The map's nodes, in the order they were added. The first is the root, whose @id is #this.
connections
Parent-to-child edges by array index, each { "start": i, "end": j }. They agree with parent.
start
In an edge, the index of the parent node.
end
In an edge, the index of the child node.
selectedNode
Index of the selected node. View state; writers may set it to the newest node, or the root when the map is complete.

A node

name
The node's text, one line.
parent
The node's parent, by @id (typed @id). Absent on the root. Since 0.2.
link
An http(s) URL, or a reference relative to the map's own URL (a .json/.jsonld target is another map). Typed @id. Other schemes are not followed. In Nostr events, absolute only.
image
An http(s) image URL shown with the node's text. Typed @id.
x
Horizontal centre of the node in map units (about CSS pixels at 100%). Optional layout.
y
Vertical centre of the node in map units; grows downward. Optional layout.
bgColor
A CSS colour for the node's background, ideally a soft pastel. A presentation hint.
size
A number scaling the node's text and box; 1 is normal. Renderers clamp it and may ignore it.
collapsed
true when the node's branch is folded.
