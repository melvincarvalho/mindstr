Shortcuts

EnterAdd sibling
F2 / double-clickRename
DeleteDelete node (children move up)
Ctrl+KSet link
O / click link textOpen link
Arrow keysMove selection
Ctrl+Z / Ctrl+Shift+ZUndo / redo
Ctrl+SSave
F, +, −, wheelFit / zoom
EscCancel edit / deselect

Drag the background to pan, pinch to zoom, double-tap a node to rename. Open any map with ?uri= and a relative or absolute URL to a .json or .jsonld file.
