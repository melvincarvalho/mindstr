    Help

    Mouse and touch

    Drag a nodeMove it with its branch (hold Alt for just the node)
    Drop on a nodeMake it a child of that node
    Double-click / double-tapRename
    Click ↗ in a nodeOpen its link
    Click the round badgeFold or unfold a branch
    Drag background · scrollPan
    Pinch · Ctrl+scroll · ＋ −Zoom

    Keyboard

    Tab / InsertAdd child (Esc then Tab leaves the map)
    EnterAdd sibling
    F2Rename
    Arrow keysMove between nodes
    SpaceFold / unfold
    DeleteDelete node (children move up)
    Ctrl+K · OSet link · open link
    Ctrl+C / VCopy branch · paste a branch or any text outline
    Ctrl+FFind
    L · FTidy layout · fit to screen
    Ctrl+Z / Ctrl+Shift+ZUndo / redo
    Ctrl+SSave
